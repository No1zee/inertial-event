# NovaStream Voice & Identity Guidelines

## Core Principles
1. **Human-First**: Prioritize natural, emotive, and welcoming language. Avoid technical jargon or system-centric descriptors.
2. **Cinematic Mastery**: Use terminology that evokes the feeling of a premium movie theater or a curated film festival.
3. **High-Trust**: Maintain a professional, stable, and reliable tone.
4. **Direct & Efficient**: Facilitate the user's journey—Find, Decide, Play, Continue—without unnecessary friction.

## Terminology Map

| Legacy / Robotic Term | Human-First Replacement | Rationale |
| :--- | :--- | :--- |
| Vault / Foundry / Command Center | Home / Sanctuary / Library | Moves away from "technical system" to "personal space." |
| Directorial Controls | Creative Controls / Personalization | Emphasizes the user's role without being overly formal. |
| Archives / Database | Collection / Filmography / Heritage | Evokes a sense of curation rather than just data storage. |
| Neural Sync / Data Handshake | Syncing / Connecting | Simplified, high-trust language. |
| System Status: Optimized | Everything is Ready | Friendly and clear. |

## Interaction Voice
- **Micro-labels**: Use lowercase for a modern, minimalist feel, or uppercase for institutional authority when needed (e.g., categories).
- **Feedback**: Provide satisfying, subtle audio/visual feedback for every action.
- **Empty States**: Be encouraging. Instead of "No data," use "Your collection is waiting for its first masterpiece."

## Accessibility Standards
- Minimum contrast ratio of 4.5:1 for all primary text.
- Clear focus indicators for keyboard navigation.
- Screen-reader friendly labels (ARIA) for all interactive elements.
